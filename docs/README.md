欢迎来到 Build AI Template 项目的官方文档站点。这里提供了项目完整的使用指南、API 参考和最佳实践。

## ✨ 特性

- **AI 优先**: 专为快速构建生产级 AI 应用而设计，深度集成 OpenAI。
- **生产就绪**: 提供从原型到生产的全套解决方案，支持 Docker 一键部署。
- **现代技术栈**: 前后端分离架构，采用 Next.js, FastAPI, PostgreSQL 等流行技术。
- **完整文档**: 提供中英文双语支持、全文搜索和现代化的 UI。

## 🛠️ 技术栈

- **前端**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **后端**: FastAPI, Python 3.12, SQLModel, PostgreSQL
- **文档**: Nextra v4
- **部署**: Docker, Docker Compose

## 🚀 快速开始

### 环境要求

- Node.js >= 20.x
- pnpm >= 9.x

### 本地开发

1. **克隆项目**

   ```bash
   git clone https://github.com/open-v2ai/build-ai-template.git
   cd build-ai-template/docs
   ```

2. **安装依赖**

   ```bash
   pnpm install
   ```

3. **启动开发服务器**

   ```bash
   pnpm dev
   ```

4. **访问文档**

   在浏览器中打开 [http://localhost:4000](http://localhost:4000)
