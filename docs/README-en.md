Welcome to the official documentation site for the Build AI Template project. This site provides a complete user guide, API reference, and best practices.

## ✨ Features

- **AI First**: Designed for rapidly building production-grade AI applications with deep OpenAI integration.
- **Production Ready**: Offers a complete solution from prototype to production, with one-click Docker deployment.
- **Modern Tech Stack**: Features a decoupled architecture with popular technologies like Next.js, FastAPI, and PostgreSQL.
- **Comprehensive Documentation**: Supports both English and Chinese, with full-text search and a modern UI.

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: FastAPI, Python 3.12, SQLModel, PostgreSQL
- **Documentation**: Nextra v4
- **Deployment**: Docker, Docker Compose

## 🚀 Quick Start

### Prerequisites

- Node.js >= 20.x
- pnpm >= 9.x

### Local Development

1. **Clone the repository**

   ```bash
   git clone https://github.com/open-v2ai/build-ai-template.git
   cd build-ai-template/docs
   ```

2. **Install dependencies**

   ```bash
   pnpm install
   ```

3. **Start the development server**

   ```bash
   pnpm dev
   ```

4. **Access the documentation**

   Open [http://localhost:4000](http://localhost:4000) in your browser.
