## 🚀 方式一：Docker 一键部署（推荐）

这是最简单快速的部署方式，适合快速体验和生产环境使用。

### 前置要求

- Docker >= 26.0
- Docker Compose >= 2.25

### 部署步骤

1. **克隆项目**

  ```bash
  git clone https://github.com/open-v2ai/build-ai-template.git
  cd build-ai-template/deploy/
  ```

2. **配置环境变量**

  ```bash
  # 复制环境变量模板
  cp .env.example .env

  # 编辑环境变量文件
  vim .env  # 或使用您喜欢的编辑器
  ```

  **必需配置项**：

  ```bash
  # AI 配置（必填）
  AGENT_API_KEY=sk-proj-***
  AGENT_BASE_URL=https://api.openai.ai/v1/chat/completions
  AGENT_MODEL_NAME=gpt-4.1-mini

  # 邮件配置（必填，用于登录验证码）
  # 方式一：使用 SMTP
  MAIL_SEND_METHOD=SMTP
  MAIL_USERNAME=your-email@gmail.com
  MAIL_PASSWORD=your-app-password
  MAIL_FROM=your-email@gmail.com
  MAIL_SERVER=smtp.gmail.com
  MAIL_PORT=587

  # 方式二：使用 Resend
  # MAIL_SEND_METHOD=RESEND
  # RESEND_API_KEY=re_your-resend-api-key
  # RESEND_MAIL_FROM=your-email@your-domain.com

  # Stripe 配置（必填，用于支付模块）
  STRIPE_PUBLIC_KEY=pk-test-***
  STRIPE_PRIVATE_KEY=sk-test-***
  STRIPE_WEBHOOK_SECRET=whsec-***

  # 安全配置（建议修改）
  AUTH_SECRET_KEY=your-super-secret-key-here
  ```
  <br/>
  <Alert>
    <AlertTitle>📧 邮件配置说明</AlertTitle>
    <AlertDescription>
      <div className="mt-2 space-y-2">
        <p>您可以选择 <strong>SMTP</strong> 或 <strong>Resend</strong> 两种方式发送邮件。</p>
        <p><strong>SMTP (Gmail 用户)</strong>：需要开启两步验证并生成应用专用密码。</p>
        <p><strong>Resend 用户</strong>：需要配置 API Key 和在 Resend 验证过的发件域名邮箱。</p>
        <p><strong>测试环境</strong>：可以使用 <code>AUTH_IS_DEBUG=True</code> 和 <code>AUTH_DEBUG_CODE=888888</code> 跳过邮件验证。</p>
      </div>
    </AlertDescription>
  </Alert>

3. **打包镜像**

  ```bash
  make build-all
  ```

4. **启动服务**

  ```bash
  # 一键启动所有服务
  docker compose up -d

  # 查看服务状态
  docker compose ps

  # 查看日志（可选）
  docker compose logs -f
  ```

5. **访问应用**

- **用户界面**: http://localhost:8081
- **管理后台**: http://localhost:8081/admin
- **API 文档**: http://localhost:8081/v1/api/docs
- **项目文档**: http://localhost:8082

## 🛠️ 方式二：开发环境运行

适合开发者进行功能开发和定制。

**前置要求**

- **后端**：Python >= 3.12，uv >= 0.6
- **前端**：Node.js >= 18.19，pnpm >= 10.11

1. **准备数据库**

```bash
# 克隆项目
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template

# 启动 PostgreSQL（使用 Docker）
bash api/scripts/run_postgres.sh

# 启动 Redis（使用 Docker）
bash api/scripts/run_redis.sh
```

2. **配置并运行后端**

```bash
cd api/

# 安装依赖
uv sync

# 激活虚拟环境
source venv/bin/activate  # Linux/macOS
# 或 venv\Scripts\activate  # Windows

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件
vim .env

# AI 配置（必填）
AGENT_API_KEY=sk-proj-***
AGENT_BASE_URL=https://api.openai.ai/v1/chat/completions
AGENT_MODEL_NAME=gpt-4.1-mini

# 邮件配置（必填，用于登录验证码）
# 方式一：使用 SMTP
MAIL_SEND_METHOD=SMTP
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM=your-email@gmail.com
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587

# 方式二：使用 Resend
# MAIL_SEND_METHOD=RESEND
# RESEND_API_KEY=re_your-resend-api-key
# RESEND_MAIL_FROM=your-email@your-domain.com

# Stripe 配置（必填，用于支付模块）
STRIPE_PUBLIC_KEY=pk-test-***
STRIPE_PRIVATE_KEY=sk-test-***
STRIPE_WEBHOOK_SECRET=whsec-***

# 运行数据库迁移（可选）
alembic upgrade head

# 启动开发服务器（端口 8000）
python -m app.main
```

3. **配置支付模块**

```bash
cd api/
source venv/bin/activate

# 登录 Stripe
stripe login
stripe listen --forward-to localhost:8000/api/v1/orders/stripe/webhook
# 复制生成的 webhook 密钥到 .env 文件中
STRIPE_WEBHOOK_SECRET=whsec_cexxx
```

4. **配置并运行应用前端**

```bash
# 新开终端窗口
cd web/

# 安装依赖
pnpm install

# 配置环境变量
cp .env.example .env
vim .env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

然后，启动开发服务器：

```bash
# 启动开发服务器（端口 3000）
pnpm dev
```

5. **配置并运行文档前端**

```bash
# 新开终端窗口
cd docs/

# 安装依赖
pnpm install

# 启动开发服务器（端口 4000）
pnpm dev
```

6. **访问应用**

- **用户界面**: http://localhost:3000
- **管理后台**: http://localhost:3000/admin
- **API 文档**: http://localhost:3000/v1/api/docs
- **项目文档**: http://localhost:4000

## ✅ 验证部署

### 1. 检查服务状态

```bash
# Docker 部署
docker compose ps

# 开发环境
curl http://localhost:8000/health  # 后端健康检查
curl http://localhost:3000         # 前端访问
```

### 2. 测试核心功能

1. **用户注册登录**
   - 访问应用首页
   - 点击登录，输入邮箱
   - 检查邮箱验证码（或使用调试码 888888）

2. **AI 对话测试**
   - 登录后创建新对话

   - 访问 `/admin` 路径
   - 查看用户管理、对话统计等功能

## 🚨 常见问题

<br/>
<Alert>
  <AlertTitle>❌ 服务启动失败</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>检查端口占用</strong>：Docker 部署确保 8081、8082 端口未被占用，开发环境执行确保 8000、3000、4000 端口未被占用。</p>
      <p><strong>检查 Docker</strong>：确保 Docker 服务正在运行。</p>
      <p><strong>查看日志</strong>：使用 <code>docker compose logs -f</code> 查看错误信息。</p>
    </div>
  </AlertDescription>
</Alert>

<br/>
<Alert>
  <AlertTitle>❌ AGENT 响应失败</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>检查 API Key</strong>：确保 AGENT API Key 有效且有余额。</p>
      <p><strong>检查网络</strong>：确保服务器可以访问 AGENT API。</p>
      <p><strong>检查模型</strong>：确认模型名称正确（如 <code>gpt-4.1-mini</code>）。</p>
