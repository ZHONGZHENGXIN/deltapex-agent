## 📦 已发布版本

### v0.1.0 - 初始版本
<br/>
<Alert>
  <AlertTitle>🎉 初始版本发布</AlertTitle>
  <AlertDescription>
    Build AI Template v0.1.0 发布！这是项目的第一个公开版本，提供了一个强大的 AI 应用开发起点。
  </AlertDescription>
</Alert>

**🆕 核心功能**

- **🤖 AI 对话系统**: 集成 OpenAI API，支持流式响应和多轮对话。
- **👤 用户系统**: 包含完整的用户注册、登录和会话管理。
- **🛠 管理后台**: 提供基础的用户管理和对话监控功能。
- **🚀 一键部署**: 使用 Docker 和 Docker Compose 实现快速部署。

**🔧 技术栈**

- **后端**: FastAPI + Python 3.12 + SQLModel + PostgreSQL + Redis
- **前端**: Next.js 15.3 + React 19 + TypeScript + Tailwind CSS + Shadcn UI
- **AI**: OpenAI API
- **部署**: Docker + Docker Compose
