# 🔧 故障排除

本页面收集了 Build AI Template 使用过程中的常见问题和解决方案。如果您遇到问题，请先查看本指南。

## 🚨 紧急问题快速解决

### 服务无法启动
<br/>
<Alert>
  <AlertTitle>❌ 问题：Docker 容器启动失败</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>症状</strong>：运行 <code>docker compose up -d</code> 后服务无法正常启动</p>
      <p><strong>快速解决</strong>：</p>
      <div className="ml-4 space-y-1">
        <p>1. 检查端口占用：<code>lsof -i :8080</code></p>
        <p>2. 查看日志：<code>docker compose logs -f</code></p>
        <p>3. 重新构建：<code>docker compose down && docker compose up -d --build</code></p>
      </div>
    </div>
  </AlertDescription>
</Alert>
