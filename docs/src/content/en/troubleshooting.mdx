# 🔧 Troubleshooting

This page collects common issues and solutions encountered when using Build AI Template. If you encounter problems, please check this guide first.

## 🚨 Emergency Quick Fixes

### Service Won't Start
<br/>
<Alert>
  <AlertTitle>❌ Issue: Docker containers fail to start</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Symptoms</strong>: Services don't start properly after running <code>docker compose up -d</code></p>
      <p><strong>Quick Fix</strong>:</p>
      <div className="ml-4 space-y-1">
        <p>1. Check port usage: <code>lsof -i :8080</code></p>
        <p>2. View logs: <code>docker compose logs -f</code></p>
        <p>3. Rebuild: <code>docker compose down && docker compose up -d --build</code></p>
      </div>
    </div>
  </AlertDescription>
</Alert>
