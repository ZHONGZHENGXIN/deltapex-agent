## 🚀 Method 1: Docker One-Click Deployment (Recommended)

This is the simplest and fastest deployment method, suitable for a quick experience and for production use.

### Prerequisites

- Docker >= 26.0
- Docker Compose >= 2.25

### Deployment Steps

1. **Clone the Project**

  ```bash
  git clone https://github.com/open-v2ai/build-ai-template.git
  cd build-ai-template/deploy/
  ```

2. **Configure Environment Variables**

  ```bash
  # Copy the environment variable template
  cp .env.example .env

  # Edit the environment variable file
  vim .env  # or use your favorite editor
  ```

  **Required Configuration Items**:

  ```bash
  # AI Configuration (Required)
  AGENT_API_KEY=sk-proj-***
  AGENT_BASE_URL=https://api.openai.ai/v1/chat/completions
  AGENT_MODEL_NAME=gpt-4.1-mini

  # Email Configuration (Required for login verification codes)
  # Method 1: Use SMTP
  MAIL_SEND_METHOD=SMTP
  MAIL_USERNAME=your-email@gmail.com
  MAIL_PASSWORD=your-app-password
  MAIL_FROM=your-email@gmail.com
  MAIL_SERVER=smtp.gmail.com
  MAIL_PORT=587

  # Method 2: Use Resend
  # MAIL_SEND_METHOD=RESEND
  # RESEND_API_KEY=re_your-resend-api-key
  # RESEND_MAIL_FROM=your-email@your-domain.com

  # Stripe Configuration (Required for payment module)
  STRIPE_PUBLIC_KEY=pk-test-***
  STRIPE_PRIVATE_KEY=sk-test-***
  STRIPE_WEBHOOK_SECRET=whsec-***

  # Security Configuration (Recommended to change)
  AUTH_SECRET_KEY=your-super-secret-key-here
  ```
  <br/>
  <Alert>
    <AlertTitle>📧 Email Configuration Guide</AlertTitle>
    <AlertDescription>
      <div className="mt-2 space-y-2">
        <p>You can choose to send emails via <strong>SMTP</strong> or <strong>Resend</strong>.</p>
        <p><strong>SMTP (for Gmail users)</strong>: You need to enable two-step verification and generate an app-specific password.</p>
        <p><strong>Resend users</strong>: You need to configure an API Key and use a sender email from a domain verified in Resend.</p>
        <p><strong>For testing environment</strong>: You can use <code>AUTH_IS_DEBUG=True</code> and <code>AUTH_DEBUG_CODE=888888</code> to bypass email verification.</p>
      </div>
    </AlertDescription>
  </Alert>

3. **Build Images**

  ```bash
  make build-all
  ```

4. **Start the Services**

  ```bash
  # Start all services with a single command
  docker compose up -d

  # Check the status of the services
  docker compose ps

  # View logs (optional)
  docker compose logs -f
  ```

5. **Access the Application**

- **User Interface**: http://localhost:8081
- **Admin Panel**: http://localhost:8081/admin
- **API Documentation**: http://localhost:8081/v1/api/docs
- **Project Documentation**: http://localhost:8082

## 🛠️ Method 2: Running in a Development Environment

This is suitable for developers who want to develop and customize features.

**Prerequisites**

- **Backend**: Python >= 3.12, uv >= 0.6
- **Frontend**: Node.js >= 18.19, pnpm >= 10.11

1. **Prepare the Database**

```bash
# Clone the project
git clone https://github.com/open-v2ai/build-ai-template.git
cd build-ai-template

# Start PostgreSQL (using Docker)
bash api/scripts/run_postgres.sh

# Start Redis (using Docker)
bash api/scripts/run_redis.sh
```

2. **Configure and Run the Backend**

```bash
cd api/

# Install dependencies
uv sync

# Activate the virtual environment
source venv/bin/activate  # For Linux/macOS
# or venv\Scripts\activate  # For Windows

# Configure environment variables
cp .env.example .env
# Edit the .env file
vim .env

# AI Configuration (Required)
AGENT_API_KEY=sk-proj-***
AGENT_BASE_URL=https://api.openai.ai/v1/chat/completions
AGENT_MODEL_NAME=gpt-4.1-mini

# Email Configuration (Required for login verification codes)
# Method 1: Use SMTP
MAIL_SEND_METHOD=SMTP
MAIL_USERNAME=your-email@gmail.com
MAIL_PASSWORD=your-app-password
MAIL_FROM=your-email@gmail.com
MAIL_SERVER=smtp.gmail.com
MAIL_PORT=587

# Method 2: Use Resend
# MAIL_SEND_METHOD=RESEND
# RESEND_API_KEY=re_your-resend-api-key
# RESEND_MAIL_FROM=your-email@your-domain.com

# Stripe Configuration (Required for payment module)
STRIPE_PUBLIC_KEY=pk-test-***
STRIPE_PRIVATE_KEY=sk-test-***
STRIPE_WEBHOOK_SECRET=whsec-***

# Run database migrations (optional)
alembic upgrade head

# Start the development server (port 8000)
python -m app.main
```

3. **Configure the Payment Module**

```bash
cd api/
source venv/bin/activate

# Login to Stripe
stripe login
stripe listen --forward-to localhost:8000/api/v1/orders/stripe/webhook
# Copy the generated webhook secret to the .env file
STRIPE_WEBHOOK_SECRET=whsec_cexxx
```

4. **Configure and Run the Application Frontend**

```bash
# Open a new terminal window
cd web/

# Install dependencies
pnpm install

# Configure environment variables
cp .env.example .env
vim .env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

Then, start the development server:

```bash
# Start the development server (port 3000)
pnpm dev
```

5. **Configure and Run the Documentation Frontend**

```bash
# Open a new terminal window
cd docs/

# Install dependencies
pnpm install

# Start the development server (port 4000)
pnpm dev
```

6. **Access the Application**

- **User Interface**: http://localhost:3000
- **Admin Panel**: http://localhost:3000/admin
- **API Documentation**: http://localhost:3000/v1/api/docs
- **Project Documentation**: http://localhost:4000

## ✅ Verify Deployment

   - Visit the application's home page

## 🚨 Common Issues

<br/>
<Alert>
  <AlertTitle>❌ Service Fails to Start</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Check for port conflicts</strong>: For Docker deployment, ensure ports 8081 and 8082 are not in use. For the development environment, ensure ports 8000, 3000, and 4000 are not occupied.</p>
      <p><strong>Check Docker</strong>: Make sure the Docker service is running.</p>
      <p><strong>View logs</strong>: Use <code>docker compose logs -f</code> to check for error messages.</p>
    </div>
  </AlertDescription>
</Alert>

<br/>
<Alert>
  <AlertTitle>❌ AGENT Fails to Respond</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Check API Key</strong>: Ensure the AGENT API Key is valid and has a sufficient balance.</p>
      <p><strong>Check network</strong>: Ensure the server can access the AGENT API.</p>
      <p><strong>Check model</strong>: Confirm the model name is correct (e.g., <code>gpt-4.1-mini</code>).</p>
    </div>
  </AlertDescription>
</Alert>

<br/>
<Alert>
  <AlertTitle>❌ Email Fails to Send</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Cloud Provider Blocking</strong>: Most cloud providers may block SMTP services. You can use <a href="https://resend.com/" target="_blank" rel="noopener noreferrer">Resend</a> as an alternative.</p>
      <p><strong>Testing Environment</strong>: You can set <code>AUTH_IS_DEBUG=True</code> and <code>AUTH_DEBUG_CODE=888888</code> to bypass email verification for direct login, which is convenient for local development and testing.</p>
    </div>
  </AlertDescription>
</Alert>

<br/>
<Alert>
  <AlertTitle>❌ Payment module configuration failed</AlertTitle>
  <AlertDescription>
    <div className="mt-2 space-y-2">
      <p><strong>Check Stripe</strong>: Ensure the Stripe service is running.</p>
      <p><strong>Check webhook secret</strong>: Make sure the webhook secret is correct.</p>
      <p><strong>Check Stripe account</strong>: Verify that the Stripe account is set up correctly.</p>
    </div>
  </AlertDescription>
</Alert>
