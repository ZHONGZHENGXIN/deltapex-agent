## 📦 Released Versions

### v0.1.0 - Initial Release
<br/>
<Alert>
  <AlertTitle>🎉 Initial Release</AlertTitle>

  </AlertDescription>

**🆕 Core Features**

- **🤖 AI Chat System**: Integrated with OpenAI API, supports streaming responses and multi-turn conversations.
- **👤 User System**: Includes complete user registration, login, and session management.
- **🛠 Admin Dashboard**: Provides basic user management and conversation monitoring.
- **🚀 One-Click Deployment**: Fast deployment using Docker and Docker Compose.

**🔧 Tech Stack**

- **Backend**: FastAPI + Python 3.12 + SQLModel + PostgreSQL + Redis
- **Frontend**: Next.js 15.3 + React 19 + TypeScript + Tailwind CSS + Shadcn UI
- **AI**: OpenAI API
- **Deployment**: Docker + Docker Compose
