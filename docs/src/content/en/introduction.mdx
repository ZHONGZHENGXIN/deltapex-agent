# Build AI Template

**Build AI Template** is an open-source template project for rapidly building AI applications, built with **FastAPI** and **Next.js**. It supports integration with multiple AI platforms and provides complete user management, chat systems, and admin dashboards.

## 🎯 Project Features

### Why Choose Build AI Template?

- **🚀 Ready to Use**: Complete AI application solution, no need to start from scratch
- **🔧 Highly Customizable**: Modular design for easy extension and customization
- **🌍 Multi-Platform Support**: Integration with OpenAI, Dify, FastGPT, Coze and other mainstream AI platforms
- **📱 Modern Interface**: Beautiful responsive design based on Shadcn UI
- **🔒 Enterprise Security**: Comprehensive user authentication and permission management
- **📊 Data Insights**: Detailed usage statistics and admin dashboard

## 🏗️ Technical Architecture

### Backend Tech Stack

- **Framework**: FastAPI + Python 3.12
- **Database**: PostgreSQL + SQLModel + Alembic
- **Cache**: Redis
- **AI Integration**: OpenAI API + Multi-platform Agent support
- **Authentication**: JWT + Email verification codes
- **Package Management**: uv

### Frontend Tech Stack

- **Framework**: Next.js 15.3 + React 19 + TypeScript
- **UI Components**: Shadcn UI + Tailwind CSS
- **Internationalization**: next-intl
- **State Management**: React Hooks
- **Package Management**: pnpm

### Deployment Technology

- **Containerization**: Docker + Docker Compose
- **Reverse Proxy**: Nginx
- **Data Persistence**: PostgreSQL + Redis data volumes
